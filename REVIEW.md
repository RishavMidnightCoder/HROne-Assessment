Also note anything you looked at and decided was **not** a defect, and why.
Looked at and decided these are not defects
- `load_dotenv()`: it does not override existing environment variables by default, so real environment variables win, as the contract requires.
- Sync `def` endpoints with the sync PyMongo client: FastAPI runs them in a thread pool and `MongoClient` is thread-safe, so they do not block the server.
- `punched_at` with a fractional part such as `.5`: the starter's `Optional[int]` already rejected it with 422.
- `GET /attendance?page_size=2` returned `total: 9` with 2 items, so `total` correctly reflects the query (though it was computed in memory).
- String comparison of `date` with `$gte` / `$lte`: fine for zero-padded `YYYY-MM-DD` strings once the format is validated, which the fix now does.
